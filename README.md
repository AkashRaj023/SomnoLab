## SomnoLab – Sleep Pattern Analytics System
> SomnoLab is a Python-based sleep analytics system designed to process and analyze sleep data, detect irregular patterns, and provide meaningful insights into sleep quality. It leverages data analysis, anomaly detection, and visualization techniques to help users better understand their sleep behavior.


## What it does
> Analyzes 5k+ sleep records
> Detects weird sleep patterns (~85% accuracy)
> Tracks metrics like sleep duration & cycles
> Visualizes data with clean graphs


## Run it
git clone https://github.com/AkashRaj023/somnolab.git
cd somnolab
pip install -r requirements.txt
python main.py

## output
> Sleep insights
> Pattern detection
> Graphs that actually make sense
